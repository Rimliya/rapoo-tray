# rapoo-tray 开发路线与未完成项

更新日期：2026-11-01

本文档记录 v1.16.0 开发周期的实际状态。已完成项经过本地构建和回归测试；未完成项明确保留，不作为已经承诺的功能。

## 已完成

### 状态 OSD 自定义

- 支持底部居中、右下角、右上角、左上角四种位置。
- 支持跟随鼠标显示器或固定主显示器。
- 支持 75%–150% 缩放、40%–100% 不透明度、800–8000 ms 停留时间。
- 支持 X/Y 偏移并限制在工作区内。
- 设置页提供“预览状态 OSD”，有未保存修改时会先保存再预览。
- 使用 Per-Monitor DPI 和 GDI+ ClearType 抗锯齿。

### 全局快捷键套件

- 快速面板呼出。
- 切换下一个配置档案。
- 切换下一个 DPI 档位。
- 循环可用性能模式。
- 开关状态 OSD。
- 支持录制、禁用、恢复默认和组合键冲突检测。
- 注册失败会回传到设置中心，不再静默失败。

### 应用内更新

- 通过 GitHub Release API 检查正式版本。
- 下载官方安装包和 `.sha256` 旁车文件。
- 强制校验 SHA256。
- 如果文件带 Authenticode 签名，则额外使用 WinVerifyTrust 验证发布者。
- 校验通过后可直接启动安装器；未签名包显示 SmartScreen 风险提示。
- 哈希错误或下载大小异常会拒绝自动安装。

### 配置快照

- 保存、新增、删除、应用和导入配置前自动生成 `.rapoo` 快照。
- 最多保留最近 20 份。
- 关于页支持手动备份、刷新和恢复。
- 恢复前再次自动备份当前配置。
- 快照使用现有 `.rapoo` 格式，可复用导入流程。

### 设备诊断

- 新增诊断页。
- 使用 Raw Input 统计系统收到的鼠标输入间隔、实测频率、抖动和最大间隔。
- 显示型号、连接、电量、当前 DPI、DPI 范围、档位数量、当前回报率和性能模式。
- 支持导出脱敏文本诊断报告。
- 测试页面可正常注册和停止 Raw Input。

### 字体与构建

- WPF 使用 Ideal + ClearType，整数磅值和 HarmonyOS Sans Medium。
- 原生窗口使用 `CLEARTYPE_NATURAL_QUALITY`。
- OSD 使用 `ClearTypeGridFit` 和更高文字对比度。
- 安装器与设置中心截图已同步到 README。

### 代码签名基础设施

- 保留 PFX Base64 + 密码参数的可选签名脚本。
- 支持 `Set-AuthenticodeSignature` 签名和时间戳验证。
- 正式发布工作流生成安装包和便携包 SHA256 文件。
- v1.16.0 Release 不调用签名步骤；本地已用测试证书验证脚本可用。

## 未完成 / 待外部条件

### 生产受信任代码签名

**v1.16.0 不启用。** 当前发布策略为未签名 Release + SHA256 校验。

后续如需改善 SmartScreen 信任，可以提供受信任的 OV/EV 代码签名证书，或选择 Azure Trusted Signing 方案。在此之前：

- Release 页面和 README 必须明确标记未签名；
- 不得宣称“已受信任签名”；
- 自签名只用于本机测试。

### 多设备 / 多接收器

**未开始。** 当前后端仍以单个鼠标和一个活动设备状态为核心。该功能需要重构：

- 设备身份与状态隔离；
- 每设备配置、DPI、电量历史和 OSD 状态；
- 多接收器连接与切换；
- 共享托盘和设置中心的状态模型。

### 高级自动化规则

**未开始。** 当前仅支持前台程序路径匹配。后续可增加：

- 电源状态、时间段、窗口标题和全屏状态条件；
- 规则优先级、冲突预览和测试运行；
- 规则命中历史与调试信息。

### 完整 HID 诊断与设备能力库

**未开始。** 当前诊断只汇总系统可见状态，不解码 HID 原始报文。

后续需要：

- 读取并脱敏导出 HID 报告；
- 寄存器读取/写入历史；
- 按 PID/固件版本建立设备能力库；
- 更准确地识别不同型号的 DPI、性能模式和电池能力。

### 回报率验证的进一步精确化

当前实现测量的是 Windows Raw Input 到达时间，不是 USB/HID 抓包时间，也不区分多只鼠标。后续可：

- 按设备路径过滤目标鼠标；
- 记录丢包和报告队列行为；
- 增加短时高精度采样图；
- 明确区分“配置值 / 驱动值 / Raw Input 实测值”。

### 其他未完成项

- 中英文界面切换。
- WinGet / Microsoft Store 分发。
- Rainmeter 或独立桌面小组件。
- WebDAV / 本地局域网配置同步。
- 完整设置备份（当前快照只包含配置档案、默认项和自动切换开关，不含 OSD 与快捷键设置）。
- 安装包签名后的正式 SmartScreen 信誉验证。
- 自动更新失败后的降级渠道或回滚版本管理。

## 明确不做

以下功能不属于当前产品的工作范围：

- 鼠标固件更新。
- 鼠标按键重映射、宏录制或去抖等硬件寄存器设置。

## 建议后续优先级

1. 如未来启用代码签名，配置生产证书并验证首个受信任签名 Release。
2. 多设备状态模型设计。
3. 高级自动化规则与冲突预览。
4. 按设备过滤 Raw Input，并增加 HID 报告诊断。
5. 完整设置快照与恢复。
